## Только для Claude

- Агентов, воркфлоу и многоагентные ревью запускать только после прямого
  «да» владельца в чате — даже если включён ultracode. Работать самому:
  читать код, гонять `npm run test:snap`, проверять `npm run shot`.
- Владелец — хозяин производства. Факты цеха спрашивать у него, а не
  выводить из кода. В чате — по-русски и подробно, с картинками
  (`npm run shot`, отправлять файлом).
