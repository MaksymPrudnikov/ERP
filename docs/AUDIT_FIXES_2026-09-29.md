## Улучшения интерфейса

- Видимый статус `Editing here` / `Read only`, время успешного сохранения и
  кнопка передачи управления. Export JSON остаётся резервной копией вне браузера.
- Production показывает используемые станции; плитки переносятся по ширине,
  Shipping доступна отдельной кнопкой. Есть сводка Hold, просроченных заказов,
  компонентов без пары и записей Recut. Станционные числа подписаны как компоненты.
- Cut size и Finished size подписаны явно; работы в очереди и карточке CNC
  относятся к одному проходу. Стикер и экран используют зафиксированный маршрут.
- Навигация доступна с клавиатуры. Phase 1 скрыта из рабочего интерфейса.
- `CSV exported` сообщает создание файла, `print requested` — запрос печати.
  Эти действия не подтверждают импорт в QuickBooks или выход этикетки принтером.

## Формат и совместимость

`productionRoute` содержит `{key, at, route:{codes, shipping, services}}` для
начатого компонента. `stationScan` может иметь `step`, `actionId`, `joined`.
Старые сканы без этих полей читаются; начатый маршрут фиксируется при первом
скане новой версии. Старые изменения справочников до установки не реконструируются.

`financeExportBatch` содержит `{batch, at, name, csv}`. Старые отметки экспорта
сохраняются, но исходный CSV до v5.99 неизвестен: приложение сообщает об этом,
а не создаёт изменённый файл под старым именем. Сигнатура платежа учитывает
валюту и заметку; старые подписи могут появиться в новой выгрузке как corrected.

JSON Export теперь использует `{format:'glass-erp', schemaVersion:1, exportedAt,
data:DB}`. Полный старый экспорт без конверта принимается. Частичные структуры
разрешены для внутренней нормализации, но UI не заменяет ими всю базу.
Перед импортом отдельный ключ `glazing_system_v1-before-import` сохраняет базу,
поэтому `Restore pre-import backup` отменяет замену. Следующая замена обновляет
эту копию: это один уровень восстановления, а не архив всех резервных копий.
Нечитаемый исходный ключ не затирается стартом приложения. При замене в режиме
восстановления исходный текст скачивается отдельно перед записью исправной базы.

## Приёмка и границы

- `npm test` и `npm run test:dist`: **985 проверок** в каждой версии,
  включая **31** новых сценариев `test/audit-fixes.js`.
- `npm run check:build`, `node build/check-manifest.js`: сборки воспроизводимы,
  порядок модулей и оболочка проверены.
- Просмотр Finance, Production и CNC на desktop и tablet; нет ошибок JS.

База относится к одному профилю браузера и месту открытия приложения. Между
компьютерами общей базы нет. Устройства с разными базами не обмениваются сканами.
При первом переходе на v5.99 закройте вкладки старой версии: их код ещё не
участвует в блокировке записи. Только одна вкладка новой версии меняет данные в момент времени; другая принимает управление
явно. Несохранённые Sales/Finance блокируют передачу; старый черновик
платежа не перезаписывает изменение из другой вкладки. Это ограничение выбранной автономной версии. Web Locks требуется для
редактирования; безопасная замена для устаревшего браузера — современный Chrome,
Edge, Firefox или Safari, где API доступен в используемом контексте.

Физические размеры стекла и качество обработки подтверждает цех. Finished size
на экране — размер по заказу, а не результат измерения датчиком. Готовность и
выдача остаются явными действиями Shipping. CSV импортируется в QuickBooks вручную.
Факт печати браузер не получает. Машинные программы по-прежнему только для
проверки с оператором по `docs/MACHINE_EXPORT_STATUS.md`.
