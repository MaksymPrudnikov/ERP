## Как проверить

1. Optimization → To verify: выбрать заказ, Verify. При отсутствии депозита
   проверить Back, Verify anyway и Take payment.
2. To batch: отметить два заказа, Send to batch. В In production у них один
   номер; в открытом заказе строки под замком. Заказ On Hold нельзя выбрать
   для Verify/батча до Release.
3. In production → Mark ready. В Ready выбрать Mark picked up либо Mark
   delivered. При долге появляется подтверждение соответствующего способа.
4. Picked up / Delivered → выбрать заказ → Close order.
5. ← Back из Batched предупреждает, что стекло уже могло быть порезано.
6. Отменённый заказ восстановить через Sales → правой кнопкой по строке →
   Restore as New. Ранее запущенные строки сохраняют замок.

Набор автоматических проверок: 629, включая массовые действия, отсутствие
частичного батча при отмене предупреждения, оплату по ID, XSS и узкий экран.
Сборка воспроизводима при LF/CRLF. Исходный `test/run.js` сохраняет CRLF.
