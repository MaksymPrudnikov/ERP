- Стекло: `shortName`. Правка данных 10 выключает строку Glass code в PO поставщику один раз.
- Stock items: `stockItem.measures` [{name, value, unit}], Kind; `DB.stockItemEvent` (Count: было → стало, причина, заметка); `DB.inventoryArchived.stock`.
- Тара: `DB.carrierSeq` (счётчик номеров), `DB.carrierEvent` (register / print / check), `DB.carrierCount` (obs / missing).
- Ширины и порядок колонок Sales / Order Lines — пользовательские настройки.
- Старый `status: 'draft'` остаётся New; старые заказы без новых полей читаются как раньше.
