# Журнал решений Glass ERP

Здесь — что и почему решили, по датам: каждая запись `## Заголовок · дата` рассказывает, что изменилось,
с цитатами владельца, функциями и тестами. **Как устроено сейчас** — не здесь, а в `docs/GLASS_ERP_HANDOFF.md`:
его читают первым, а сюда приходят по ссылке из него или из шапки модуля.

До 12 ноября 2026 журнал и был хендоффом (1,3 МБ одним файлом); разложен по месяцам дословно на этапе 7
плана «до 10». Записи до 17 сентября 2026 — в истории git (`git show f2f6e5f:docs/HANDOFF_АРХИВ.md`).

| Файл | Что внутри |

## Как читать

Целиком не открывать. Найти запись и прочитать только её:

```bash
grep -n "^## " docs/journal/2026-10.md | grep -i shipping
```

затем открыть файл с этой строки. Поиск по имени функции или экрана — `grep -n "skidSwap" docs/journal/*.md`.

## Как писать

Поведение изменилось — новая запись **сверху** файла текущего месяца (новый месяц — новый файл `ГГГГ-ММ.md`
и строка в таблице выше): что было, что стало, решение владельца с датой и цитатой, функции и тесты.
Старые записи не переписывают. Одновременно правят свой раздел в `docs/GLASS_ERP_HANDOFF.md`, чтобы он
оставался правдой о сегодняшнем дне.
