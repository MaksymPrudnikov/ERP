## Список ДО (обход на выгрузке владельца)

Уже как Sales: Sales, Optimize (очередь, To batch, Batches, Stock, Sheets, окно батча), Shipping (Shipments,
Delivery, Skids, Backorders), Finance (Accounts, Due dates, Payments), Purchasing (все виды), Inventory (главная,
Stock items, Offcuts, Count, Journal), Customers, Agents.

Частично:
- Production (главная доска-таблица) — нет ⚙ Columns.
- Shipping (Awaiting, главная) — нет фильтра, сортировки, ⚙.
- Users › Sign-in log — нет ⚙.
- Окна: строки заказа (ширина и порядок есть, фильтра и сортировки нет), Activity log заказа, карточка клиента в
  Finance (заказы, оплаты) — только ширина и порядок.

Ничего:
- Production › Stations (= Data › Stations), Production › Terminals.
- Inventory › Sheet sizes, Inventory › Consumables.
- Data › Catalog: Materials, Works, Hardware (две таблицы); Data › Prices.
- Data настройки: Cutting (две), Dollies & Skids, NCR, Stock reasons, Trucks, Setup (charges, taxes), Data overview.
- Users (офис), Users › Production.
- Окна: Allocate (две половины), таблица в окне строк заказа «# · Qty · Width · Height · Mark · Result».

Не входят: Reports (свой движок как Looker), бланки (SVG), доски (Production board, долли) — доски и окна по клику
не ломать (решение 03.11).

## Как делать

Движок — `views/sales-list-ui.js` + `sales-list-controls.js` + `views/col-widths.js`. Список подключается через
scope (`salesListScope`), каталог колонок (`salesListCatalog`), значения из `info.memo`, таблицу рисует
`salesListTableHTML(o)`. Для экранов с двумя таблицами — scope на время отрисовки и по клику внутри
`[data-sl-scope]`.
