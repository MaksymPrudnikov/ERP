# Исходные данные, из которых собрана мастер-дата

Здесь лежат файлы, по которым заводился справочник: заполненные владельцем
таблицы цеха и прайса плюс инструкции по их заполнению. **Это исторический
вход, а не живые данные.** Живые лежат в самой системе и правятся на экране
Master Data; менять что-то здесь и ждать, что оно доедет до приложения, — не
надо, связи нет.

Положены в репозиторий 11 сентября 2026. До этого существовали **в одном
экземпляре на рабочем столе владельца** — включая `CUTTING_HANDOFF_2026-08-27.md`,
отсутствие которого карта проекта прямо называла известным пробелом. Одна копия
на одной машине — риск сам по себе, поэтому копии переехали сюда.

| Файл | Что это |
|---|---|
| `GLASS_CATALOG.csv` | каталог стекла владельца |
| `GLASS_CATALOG_ЗАПОЛНЕНИЕ.md` | как заполнять каталог стекла |
| `PRODUCTION_STATIONS.csv` | станции цеха |
| `PRODUCTION_MACHINES.csv` | станки — историческая таблица, из модели убрана (см. хендофф: станок не хранится, станция лежит полем у работы) |
| `PRODUCTION_SERVICES.csv` | услуги цеха с ценами |
| `PRODUCTION_ЗАПОЛНЕНИЕ.md` | как заполнять таблицы цеха |
| `SERVICE_RATES_ЗАПОЛНИТЬ_2026-09-10.csv` | прайс владельца «Glass Treatment Rates», разобранный по полосам толщины |

Утверждённый результат разбора — `docs/SERVICE_CATALOG_2026-09-10.md`, он и
есть действующий документ по услугам и ставкам. Файлы здесь — то, из чего он
собран.

## Чего здесь нет и почему

Два файла остались вне репозитория: `GLASS_PRODUCTS_SPIL.csv` (выгрузка из
прежней системы Spil) и `GLASS_PRODUCTS_FROM_IGDB.csv` (выгрузка отраслевой
базы IGDB, 392 КБ). Это данные, полученные из чужих систем, и решение класть
ли их в репозиторий — владельца, а не разработчика. Лежат на рабочем столе.
