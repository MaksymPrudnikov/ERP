# Agents — комиссии

Комиссия людям, которые привели клиента. Владелец, 11.10.2026: в Spiel в графе продажника пишут человека, «который
привёл этого клиента… и мы ставим ему процент с каждого заказа»; это человек со стороны, доступа к ERP у него нет, деньги
ему даёт только владелец, «возможно раз в год». Раздел видит тот, у кого в Users стоит галочка Agents; продажникам он не
нужен.

## Правила

- **Клиент — у одного человека.** Отдали клиента другому — у прежнего он уходит. Комиссия тому, кто привёл, клиента не
  передают (владелец, говорил 2–3 раза).
- **Процент — только с того, что клиент заплатил**: оплаты на заказы (Finance → Payments, без Void) за период по дате
  оплаты. По умолчанию без HST: оплата × (итог − HST) / итог заказа. Галочка **With HST** добавляет колонки с HST.
- **Новый клиент — за всё время; другой процент — с даты From** (по умолчанию сегодня). Прошлые оплаты не
  пересчитываются: каждая считается по проценту на день оплаты (владелец, 19–20.10.2026).
- **Выплата — по заказам**: в неё входит только ещё не выплаченная комиссия каждого заказа, сумма считается сама
  (владелец: «чтобы я не заплатил дважды за один и тот же заказ»). Переплата прошлой выплаты вычитается — «Overpaid
  earlier · taken off».

## Экран

Сверху период **This year · Last year · All time**, галочка **With HST**, справа **+ Person**.

- **Список людей** — как в Sales ([lists.ru.md](lists.ru.md)): Person, Contact, Customers · %, Orders, Paid, Commission,
  Paid out, To pay; по умолчанию по To pay (больше сверху), итог внизу.
- **Строка или галочка** открывает человека ниже:
  - **Orders** — заказы с оплатами в периоде: Order, Customer, Date, Order total, Paid · no HST, %, Commission;
  - **Payouts** — выплаты: дата, сумма, заметка, какие заказы закрыла; **Paid out · all time**;
  - **+ Payout** — показывает заказы, по которым есть невыплаченная комиссия (Due); отметить, сумма считается сама,
    заметка, **Save payout**. Выплату можно удалить.
  - **Edit** — карточка человека.
- **Карточка** (+ Person или Edit): **Name** (обязательно), Phone, Email, Note, **Customers** — клиент и процент (0,01–100);
  у изменённого процента — дата **From**; **+ Customer** — ещё клиент. Клиент, отданный этому человеку, уходит у
  прежнего. **Delete** убирает человека вместе с его выплатами.

Почему отдельный раздел: комиссии — деньги владельца, продажникам и цеху их знать не надо. Сервер тоже закрывает эти
записи без галочки Agents.
