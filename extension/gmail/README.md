# Glass Farm for Gmail — расширение Chrome

Панель справа в Gmail: заказ Glass Farm рядом с открытым письмом — статус, сколько готово, где стекло; кнопки
Create order, Create quote, Link to order, Open in ERP; под карточкой — конверт (текст по шаблону ERP в ответ) и
скрепка (PDF бланка к ответу). Задание — `docs/ЗАДАЧА_ПОЧТА_ЗАКАЗЫ.md` (раздел «Логика
панели»), руководство для людей — `docs/manual/gmail.ru.md` / `.en.md` (там же установка).

## Файлы

| Файл | Где работает | Что делает |
|---|---|---|
| `manifest.json` | — | Manifest V3. Разрешения: `scripting` и адреса ERP; Gmail — только для панели |
| `gmail-style.js` | вкладка Gmail | Вид панели: цвета Glass Farm (`src/styles/tokens.css`), Shadow DOM |
| `gmail.js` | вкладка Gmail | Читает открытую ветку, ищет номера заказов в тексте, рисует панель. Разметка Gmail — объект `SEL` в начале |
| `background.js` | фон | Находит вкладку ERP, пересылает запрос и ответ, выводит ERP вперёд |
| `erp.js` | вкладка ERP | Передаёт запрос странице ERP (`window.postMessage`) и ответ обратно |

Ответы даёт сама страница ERP — модуль `src/erp/mail-bridge.js`. Расширение без открытой вкладки Glass Farm ничего
не знает и показывает «Glass Farm is not open in this browser.»

## Правила

- **Сети нет.** Ни `fetch`, ни внешних адресов: только сообщения между вкладками этого Chrome. Проверяет
  `test/gmail-extension.js`.
- **Текст письма из вкладки Gmail не выходит.** В ERP уходят адрес отправителя, номера ветки и письма; при создании и
  привязке — ещё тема и дата. Номера заказов клиента ERP отдаёт списком, ищет их в тексте `gmail.js` — точно, целым
  словом, PO от 4 знаков.
- **Ничего не угадывает и само не привязывает** — только по нажатию человека. Ответ не отправляет: текст и PDF
  кладёт в поле ответа, Send нажимает человек.
- **Журнал заказа.** Письма привязанной переписки — в журнал её заказов: номер письма, адрес, имя, время (подсказка у
  даты, английский Gmail) и тема; текста нет. Поле ответа и кнопка Reply — `SEL.compose`, `SEL.reply`.
- **Разметка — `createElement` и `textContent`.** Gmail требует Trusted Types; `innerHTML` запрещён тестом.
- **Shadow DOM закрыт** (`GF_SHADOW_MODE`): скрипты Gmail панель не читают. Тест открывает его в своей копии.
- Тексты интерфейса — на английском; комментарии — по-русски.

## Адреса ERP

Списком в двух местах — `manifest.json` (`host_permissions` и второй `content_scripts`) и `ERP_MATCH` в
`background.js`; тест сверяет, что они совпадают. Новый домен ERP — строка в обоих. Что открыть, если вкладки ERP нет, —
`ERP_OPEN`.

## Проверка

- `test/gmail-extension.js` (входит в `node test/run.js`): Chromium с загруженным расширением, страница-образец Gmail с
  той же разметкой, что читает `gmail.js`, и вкладка ERP рядом; сеть подменена.
- **Разметка настоящего Gmail проверяется только на пилоте.** Если панель не видит письмо — смотреть объект `SEL` в
  `gmail.js`: Gmail иногда меняет классы.
- Установка руками: `chrome://extensions` → Developer mode → Load unpacked → эта папка.
